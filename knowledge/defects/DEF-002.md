[[BR-CART-01]] on `PATCH /api/cart/items/:productId` returned `200` for quantity 11.
The add path (`POST`) enforced the limit; the update path skipped it.

**Fixed** by sharing `checkQuantity()` between both paths. Kept as seeded defect
`qty-limit-update` so the regression suite proves it would catch it again.
