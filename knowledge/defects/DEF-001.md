# DEF-001 — Checkout refuses a lower-case country code

**Steps:** sign in, add any product, open checkout, fill a valid address with
Country `us`, a valid card, Place order.

**Expected:** the order is placed; `us` is the same country as `US`.

**Actual:** "Country is a 2-letter ISO code" (`400 VALIDATION`). The field's
placeholder says `US`, but nothing upper-cases the input, and mobile keyboards
start lower-case.

**Impact:** low — the message tells the customer what to change. Workaround:
type upper case.

**Test:** runs as `test.fail()`: it passes while the bug exists and turns red
the day it is fixed. Linked to [[FEAT-CHECKOUT]].
